# CopyPop 1.0.0 开发交付报告

任务基准日期：2026-10-18（用户时区 Asia/Shanghai）。实际执行平台：Windows 11 x64。

## 实现范围

已完成 C++20 / Qt Quick / Win32 的单进程模块化应用：剪贴板格式监听及去重、复制证据判定、MTA UIA 查询与几何降级、三种可定制动画、透明穿透非激活覆盖层、窗口拖动与按需滚动追踪、焦点光标类型提示、全屏/游戏/演示保护、首次欢迎页、八类设置、逐应用继承规则、JSON 导入导出、主题、托盘、开机启动、单实例 IPC 和本地诊断。

剪贴板延迟渲染读取使用与 UIA 分离的工作线程，分类过期时保留基础格式，避免来源应用阻塞设置窗口。

欢迎页和实时预览使用同一 QML EffectLayer；示例复制会调用 TextEdit 的真实 copy()。应用没有剪贴板历史、上传、登录、键盘钩子、注入、跨进程 SetParent 或游戏内部接口。

工程包含 MIT 许可证、Lucide/Qt/MinGW/NSIS 说明、对应 Qt 源码下载脚本与本地源码归档、示例配置、Debug/Release 预设、Windows 构建/部署脚本、NSIS 配置、自动化测试与 CI 配置。

## 验证边界与限制

未将 Chrome、Office、Electron、终端、真实游戏、IME、多显示器混合 DPI、热插拔、Windows 10、MSVC 或长时间压力场景标为通过。这些需要目标设备与应用版本的专项验收。

标准 Edit 在本机没有提供 TextPattern，因此实际命中 L2 近似几何；精确 L3 依赖目标应用的 provider。某些控件没有可靠光标范围时会跳过提示。UIA provider 永久阻塞时保持单工作线程并降级，不会强杀 COM 调用。对滚动、遮挡和前台上下文无法确认时，覆盖层优先取消。自动复制推断无法保证捕捉所有右键复制和代理剪贴板操作。

界面目前为简体中文，语言标识为后续本地化预留。程序尚未签名。完整兼容性矩阵、降级行为与建议验收步骤见 COMPATIBILITY.md。

## 2026-10-19 动画手感与调试

- 悬停切换缩短为 100 ms；选中填充以 85 ms 拉伸到目标边缘，再以 230 ms OutCubic 收回，双向和中途重定向使用当前边界。
- Copied 增加独立淡入/淡出时长、曲线和位移；两段超过总时长时等比缩短。预览结束保持透明，不突然闪回。
- 跟随改为 Qt FrameAnimation 驱动；共享 MotionFollower 以真实帧时间计算弹簧加速度，开放力度和阻尼。预览显示实际动画帧率与速度；减少动画偏好下直接跟随并保留透明度变化。
- 复制特效增加暂停/继续、进度检查，以及圆角、轮廓、流光宽度/角度、脉冲次数、消散密度/距离和选区边界开关。调试参数同时作用于预览和桌面特效。
- 目标文档、tests/ 与 scripts/test-*.ps1 已加入忽略规则并停止跟踪，本地文件保留；历史提交未重写。公开源码缺少这些文件时构建自动省略测试目标。
- 本地核心 8 项、界面/原生 6 项检查通过，含 60/144/240 Hz 合成帧间隔、双向拉伸中断、淡入淡出、暂停与拖动进度、原生提示移动连续性和停止帧回调。真实高刷新率、多屏硬件仍未专项验收。

## 2026-10-19 多行流光与自适应时长

- 预览扩展为六行中英文示例。流光按视觉行数增宽、提亮，增益为 `min(1.8, 1 + 0.25 × log2(行数))`；同一行的多个片段合并计数。大选区继续使用 Shimmer，消散特效仍可降级为 Pulse。
- 固定时长模式保留速度与曲线；自适应匀速模式使用线性播放，`实际时长 = 基础时间 × (选区横向跨度 + 光带宽度) / 400 × 时长缩放比`，默认 600 ms 和 1 倍。预览与原生覆盖层共用几何计算，原生清理计时同步实际时长。
- 调色盘改为预设色块、二维色板、色相/透明度细条与数值输入，保留页内悬浮、十六进制、确认/取消和键盘操作。
- 复制通知晚于按键释放时，保留前台剪贴板来源的近期非密码选区证据，供查询超时和关闭混合追踪时触发 Copied；移动时的跟随与淡入淡出保持完整。
- 蓝色应用图标覆盖窗口、托盘、可执行文件与安装程序。侧栏显示 Alpha，重新打开欢迎页移入常规设置。
- Release 在本地构建、部署和打包；GitHub 只同步源码，不发布便携包或安装程序。测试与目标文档保持忽略。
