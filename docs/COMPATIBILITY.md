# 兼容性与验收记录

本记录区分已执行测试与待验证场景。平台接口无法提供稳定几何时，CopyPop 会跳过或取消显示，不声称所有 Windows 软件均可精确追踪。

## 已执行环境

- Windows 11 x64，单个内置显示器，150% 缩放；Qt 检测到约 1707×1067 逻辑尺寸。
- Qt 6.11.1 官方 mingw_64 Kit；Qt 自带 GCC 13.1.0；CMake 4.3；Ninja。
- Release 和 Debug 构建，CTest 的 core、ui_native 两组测试。
- Qt 安装中存在可选 QmlAssetDownloader/TaskTree 和 Vulkan 头文件探测警告；应用没有使用这些模块，构建通过。部署时存在可选 Direct3D 12 编译器缺失提示；默认 Qt D3D11 路径运行通过。

## 能力与降级

- **L3**：UIA TextPattern 提供的精确、可见、多行矩形。不同软件的 UIA provider 完整性不同。
- **L2**：标准 Win32 Edit 的索引/位置近似几何，或已确认有选区时的小型控件边界。能力仍用于诊断，复制动画降级为鼠标光标旁的 Copied 提示。
- **L1**：经密码校验后的 UIA/系统插入光标。复制时使用 Copied 提示；只有确认可编辑时才显示独立的剪贴板类型图标。
- **L0**：有复制输入证据且鼠标位于来源窗口内时显示 Copied。没有可靠复制证据则跳过。
- **Off**：全屏、演示/忙碌、已知游戏、用户排除、暂停及受保护控件。

UIA 每次查询有 180ms 结果有效期。超时后不接受晚到结果，对对应应用退避 30 秒。正常能力信息缓存 60 秒，新的焦点/复制操作仍会重检。COM provider 可以永久阻塞；程序不会强杀线程，也不会不断创建替代线程。若唯一工作线程无法恢复，后续 UIA 查询也会降级，重新启动可恢复工作线程。主界面与托盘继续工作。

COM 和事件订阅初始化也在同一工作线程中完成。初始化尚未完成时不提交选区请求，不占用查询预算；复制事件仍可按输入证据走 L0 降级。

基础剪贴板格式只查询格式标识；可能触发来源应用延迟渲染的文本读取在单独的有界工作线程中进行，与 UIA 线程隔离。超过 350ms 的分类结果丢弃，保留基础“文本”类型。来源永久卡住时不会无限创建工作线程；后续链接可能暂时只能显示文本图标，退出 CopyPop 可以释放对应进程资源。

## 已知限制

- 剪贴板 API 不提供“Ctrl+C 成功”语义。前台来源和选区/按键状态用于推断；隐藏代理窗口、远程剪贴板和某些右键复制路径可能被跳过。
- UIA 不可见、禁用辅助功能、管理员权限应用、游戏渲染表面、终端以及自绘控件可能只能降级。CopyPop 不要求管理员身份或 UIAccess 来绕过这些边界。
- UIA GetCaretRange 的退化文本范围可能没有矩形；系统光标也不可用时跳过类型提示。不会靠猜测展示输入提示。
- 几何被裁剪到控件、客户区和显示器。活动动画会验证窗口、前台及中心/四角命中；复杂透明遮挡、第三方 popup 和部分 provider 的错误几何仍可能影响效果。可靠性不足时取消。
- 滚动仅在活动动画期间按需查询（约 90ms 间隔）；窗口位置验证约 33ms 间隔。缩放和分辨率变化取消当前动画。低能力控件无法保证滚动精度。
- 预测滚动默认关闭，仅短暂使用已观测的位移趋势；不直接换算滚轮增量。
- 游戏离线清单有限，基于较具体的安装路径后缀，不使用泛化 exe 名称。移动安装、第三方启动器和新游戏应手动排除。
- 语言界面目前为简体中文；配置保留语言标识，尚未提供英语翻译。
- 尚无代码签名、自动更新或云同步。安装程序已生成，未在本机执行实际安装/卸载，以免改写当前系统安装状态。

## 未验证的第三方软件及硬件矩阵

以下均需在实际版本和硬件上验收，不列为已通过：Windows 10 22H2、MSVC Kit、Chrome/Edge 网页、Office Word/Excel、Adobe、VS Code/Electron、微信、Windows Terminal、新版记事本；真实游戏独占全屏和演示模式；混合 DPI 多显示器、跨屏拖动、热插拔、远程桌面、HDR/高刷新率和不同显卡驱动；中文 IME 候选窗口；真实用户的右键复制、后台剪贴板管理器与持续压力使用。

推荐对每个目标应用执行：多行选择 → Ctrl+C → 快速连续复制 → 右键复制 → 立即滚动 → 拖动/缩放 → 切换前台/最小化 → 聚焦可编辑控件/密码框 → 输入/IME → 全屏或添加排除规则。记录实际能力等级、误显示、是否抢焦点和空闲 CPU，而非仅记录窗口能否打开。
